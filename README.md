# Problema das N Rainhas

Implementação do problema das N Rainhas utilizando o algoritmo de **Busca em Profundidade**.

O programa testa automaticamente tabuleiros de dimensão **4x4, 5x5, 6x6, 7x7 e 8x8**, buscando uma configuração em que nenhuma rainha ataque outra.

## Como executar

Instale as dependências necessárias:

```bash
pip install aigyminsper numpy
```
Execute:
```bash
python N_QueensProblem.py
```
